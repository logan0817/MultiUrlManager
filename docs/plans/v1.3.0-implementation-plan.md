# MultiUrlManager 1.3.0 开发与验收

基线：`main / c9e69b6`（1.2.0 发布后的文档提交）。方案确认：2026-11-11。开发验收版本为 `1.3.0-SNAPSHOT`；正式版本 `1.3.0` 已发布到 Maven Central，Demo versionCode 为 `9`。

## 已确定范围

- 修复默认升级不递增 revision、现代 JSON 类型静默转换、删除可选业务最后候选后无法重新添加。
- 保留 AAR 空配置的兼容行为，纠正文档与空状态，不把初始化成功当成业务地址已配置。
- JSON 文件导出已提交配置；文件导入先选择环境和合并/替换模式，再预览，确认仅应用草稿，保存后生效。
- 可新增环境；业务键只能来自包内定义或导入前已存在的配置，展示名与固定策略由宿主控制。
- 合并默认保留本机候选、备注、选择与环境名；替换仅修改选定环境候选并保留本机必选约束。
- 输入上限 256 KiB UTF-8、32 环境、1,000 候选；实际页面恢复 Parcel 预算 256 KiB，超限拒绝并保留原数据。
- 不做搜索、二维码、剪贴板导入、云同步、Compose/Flow、独立网络诊断面板或未测量的路由缓存。

## 契约与实现顺序

1. **M1 可靠性**：默认合并改变语义状态时递增 revision，连同默认基线原子保存后才发布；无变化不重复递增。严格解析新配置，旧数组及旧存储仍兼容。保留编辑会话已知业务。
2. **M2 核心交换**：独立导入结果与差异模型；`exportConfiguration`、`inspectImport`、`previewImport` 不改变现有 SaveResult 分支或模型签名。preview 不持久化，不自动切环境。
3. **M3 文件页面**：系统文件选择器、后台读写、模式与环境选择、差异预览；预览过期时重新生成，取消/解析/写入失败不改正式配置。固定模式禁导入，导出仅固定环境。
4. **M4 验收**：保留 1.0.6/1.1.0 覆盖，追加真实 1.2.0 核心/网络 ABI、源码/二进制消费和升级夹具；更新同轮产物契约，不以旧报告替代新候选。

文件格式和操作步骤以[配置交换](../configuration-transfer.md)为准。新公开接口应有 Java/Kotlin 用法和真实 AAR/R8 消费验证，详细 API 见[API 文档](../api.md)。

## 必须验证

- 默认升级、旧草稿冲突、重复刷新幂等、基线更新、失败写保护和固定模式文件隔离。
- 严格类型、重复字段、非法 URL、必选键、未知业务、重复候选、同组多选、长中文内容与超限文件。
- 导出再导入；合并保留未选择组、替换保留约束；新环境、其他环境不变、预览过期。
- 系统文件取消/不可用/读写失败；旋转和恢复；预览确认不落盘；保存冲突与存储失败；Parcel 预算。
- API 24/36 页面、存储及文件交互；1.2.0 → 1.3.0 普通数据保留与固定模式隔离；旧版本既有验收不减少。
- 中英文 README 示例和新交换示例随真实 AAR 编译并经 R8，文档链接/JSON/XML 及工作流脚本检查。
